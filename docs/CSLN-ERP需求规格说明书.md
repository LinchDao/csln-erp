# CSLN-ERP 需求规格说明书 (PRD)

## 1. 项目概述
CSLN-ERP 是一款专为服装贸易行业设计的进销存管理系统。系统核心围绕“款号-颜色-尺码”三维规格展开，支持多门店协同、多仓库调拨、复杂的客户定价体系以及精细化的订单生命周期管理。

---

## 2. 核心业务术语
| 术语 | 说明 |
| :--- | :--- |
| **款号 (Product No)** | 商品的主索引，一个款号下可对应多个 SKU。 |
| **SKU** | 最小存货单位，由“款号 + 颜色 + 尺码”唯一确定。 |
| **母单 (Order Master)** | 销售订单的主体，承载客户信息、总金额、结算状态。 |
| **子单 (Order Sub)** | 销售订单的执行单元，按发货仓库拆分，承载物流状态。 |
| **改码配货 (Replacement)** | 实际发出 SKU 与下单需求 SKU 不一致（如替代尺码），需记录差量关系。 |
| **协发 (Help-Send)** | 当归属仓库缺货时，指派其他仓库代为发货。 |
| **追回货 (Recovery)** | 售后退回或撤单追回的货品，需经过质检/确认后方可转为可用库存。 |

## 3. 功能模块需求

### 3.1 商品与规格管理
*   **多维规格**：支持商品按款号管理，关联颜色表和尺码表。
*   **图片管理**：支持商品主图及基于颜色维度的细节图。
*   **SKU 自动生成**：根据选定的颜色和尺码列表，自动生成 SKU 记录及条码。

### 3.2 客户与复杂定价体系
*   **客户等级**：支持自定义客户等级（如：批发商、零售商），并配置对应的全局折扣率。
*   **四级定价带出策略**：
    1.  **上次成交价（默认优先级最高）**：开单选择商品后，自动带出该客户最近一次购买该商品的价格。
    2.  **专属价格**：针对特定客户与特定商品设置的协议单价。
    3.  **等级折扣价**：根据客户等级折扣计算出的指导价。
    4.  **手动改价**：支持开单员在权限范围内手动输入成交价。

### 3.3 销售订单流程（核心）
*   **母子单架构**：支持一个母单拆分为多个子单（本仓、协发、调货模式）。
*   **草稿与正式口径**：
    *   **草稿单**：仅保存数据，不修改库存，不产生财务账单。
    *   **正式单**：触发库存锁定（LockQty），支持差量编辑联动库存。
*   **改码配货逻辑**：支持记录 `Target SKU`（需求）与 `Real SKU`（实发），扣减实发 SKU 的库存。
*   **状态流转**：
    *   **主单**：待审核 -> 仓库准备中 -> 部分已发货 -> 订单已完成。
    *   **子单**：待分配 -> 配货中 -> 配货完成 -> 已发货。

### 3.4 采购与入库流程
*   **采购订单**：记录供应商供货明细，支持“待入库、部分入库、已完成、取消”状态。
*   **入库审核**：采购入库单创建后默认为“待审核”，需经审核通过后才正式增加可用库存。
*   **超量控制**：严禁入库数量超过采购合同剩余待入库数量。

### 3.5 库存管理
*   **精细化库位**：实时记录每个 SKU 在不同仓库的“可用库存、锁定库存、追回货预占”。
*   **库存锁定机制**：
    *   正式开单/草稿提交 -> 增加锁定库存。
    *   仓库配货完成 -> 扣减可用库存，同时释放锁定库存。
    *   删除子单 -> 自动回退锁定库存。
*   **库存调拨**：支持仓库间的库存转移，记录申请、发出、收货及差异。

## 4. 非功能性需求与规范

### 4.1 开发技术标准
*   **后端架构**：Spring Boot 3 + MyBatis Plus + MySQL 8.0。
*   **交互规范**：
    *   查询入参统一使用 `XXXQueryDTO`。
    *   返回对象统一使用 `Result<T>` 包装。
    *   分页结果统一封装为 `PageRespDTO<T>`。
*   **异常处理**：业务校验失败统一抛出 `BusinessException`，严禁直接返回错误字符串。

### 4.2 安全与日志
*   **鉴权**：集成 JWT，支持“记住我”长效登录。
*   **审计**：核心业务操作（如修改价格、手动调整库存）必须记录 `sys_log`。
